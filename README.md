## HW3 Requirements Completed

- Centered, usable email button with extra clickable spacing using the Week 3 padding + border button technique.
- Button has a real destination within the email (`#presentation-details`) rather than a dead `#` link.
- Updated local logo and hero images.
- Responsive hero image using the Week 3 approach: fixed HTML `width` plus inline `max-width:100%`, `min-width`, and `width:100%`.
- Single-column, table-based email layout.
- Fluid outer table at 100% width and fixed 600px inner table.
- `role="presentation"` applied to layout tables.
- Background image applied to the text area with `background`, `bgcolor`, and inline CSS fallback techniques.
- Accessibility findings PDF included in `assets/`, with pros, cons/limitations, and desktop/mobile screenshots.
- Images use descriptive `alt` text.
- Email language declared with `lang="en"`.
- Semantic headings and paragraphs used for hierarchy.
- Longer text is left aligned for readability.
- No JavaScript is used for email behavior because Week 2 notes that JavaScript is not reliable in HTML email clients.
