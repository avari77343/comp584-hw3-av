## HW3 Requirements Implemented

- Centered CTA button with extra padding for a larger click/tap area.
- Button uses the padding + border email approach from the Week 3 lecture.
- Descriptive button/link text.
- Responsive hero image using the fixed HTML width + inline responsive technique from the lecture.
- Fluid outer table at 100% width.
- Fixed inner table at the recommended **600px** width.
- Single-column table-based email layout using `table`, `tr`, and `td`.
- `role="presentation"` on layout tables for screen readers.
- Most email styling placed on table cells.
- Background image on a live-text section using `background`, `bgcolor`, and inline CSS background properties.
- Descriptive image `alt` text and `lang="en"`.
- Accessibility findings PDF in `assets/`, covering **NVDA, VoiceOver, JAWS, Silktide, Axe, and Chrome**, plus pros/cons and desktop/mobile screenshots.
